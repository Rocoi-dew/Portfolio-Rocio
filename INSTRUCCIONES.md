# Proyecto Integrador — Módulo 0

## Página Web Personal (HTML & CSS)

Construye tu **portfolio personal** utilizando HTML semántico y CSS moderno (Flexbox y diseño responsive).

---

## Objetivos

- Aplicar HTML semántico (`header`, `nav`, `main`, `section`, `article`, `footer`, etc.).
- Maquetar con **Flexbox**.
- Implementar un diseño **responsive** (adaptable a móvil, tablet y escritorio).
- Publicar el resultado en **GitHub Pages**.

---

## Requisitos mínimos

El portfolio debe incluir, como mínimo, las siguientes secciones:

1. **Cabecera** con tu nombre y un menú de navegación.
2. **Sobre mí**: una breve presentación personal.
3. **Habilidades / Tecnologías**: lista de las tecnologías que conoces.
4. **Proyectos**: al menos 2 proyectos (pueden ser ejercicios del curso).
5. **Contacto**: correo, enlaces a GitHub, LinkedIn, etc.
6. **Footer** con tu nombre y el año.

### Requisitos técnicos

- HTML5 válido y semántico.
- CSS externo (no usar estilos en línea ni `<style>` en el HTML).
- Maquetación con **Flexbox**.
- Diseño **responsive** (uso de `@media queries`).
- Imágenes optimizadas y con atributo `alt`.
- Estructura de carpetas ordenada (por ejemplo: `index.html`, `css/`, `img/`).
