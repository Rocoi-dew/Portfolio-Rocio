## 🛠️ Tecnologías utilizadas

- **HTML5 Semántico:** Estructura limpia y accesible utilizando etiquetas como `header`, `main`, `section`, `article` y `footer`.
- **CSS3 Moderno:**
  - **Flexbox & Grid:** Utilizados para la creación de layouts flexibles y adaptables.
  - **Diseño Responsive:** Implementación de `@media queries` para asegurar una experiencia óptima en móviles, tablets y escritorio.
  - **Animaciones:** Efecto de "typing" para la presentación, animaciones de escala y transiciones suaves en botones y tarjetas.
  - **Variables CSS:** Uso de `:root` para una gestión coherente de la paleta de colores y tipografías.
- **Google Fonts:** Integración de *Bodoni Moda* para títulos y *DM Sans* para el cuerpo de texto.

## 📋 Características

1.  **Sección Sobre Mí:** Una presentación dinámica con efecto de escritura.
2.  **Habilidades:** Listado de tecnologías destacadas.
3.  **Proyectos:** Grid interactivo que muestra mis trabajos recientes con efectos hover y etiquetas personalizadas.
4.  **Contacto:** Enlaces directos a mis redes profesionales y correo electrónico.
